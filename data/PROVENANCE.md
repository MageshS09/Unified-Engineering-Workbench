# Data provenance

Both sample files are **self-created** for this assignment and released under **CC0 1.0** (public domain dedication). They contain no third-party or personal data.

## cube.stl
- **What:** unit cube, 12 triangles (2 per face), 8 vertices, outward-facing normals.
- **Origin:** written by script as plain ASCII STL; not exported from any CAD package.
- **Units:** STL stores no units. The workbench assumes **metres**; the cube is 1 m x 1 m x 1 m, spanning (0,0,0) to (1,1,1).
- **Format:** ASCII STL (`solid` / `facet normal` / `outer loop` / 3 x `vertex` / `endloop` / `endfacet` / `endsolid`). Binary STL is rejected.

## synthetic_temperature.csv
- **SYNTHETIC. This is NOT an actual ANSYS export.** It imitates the column layout of an ANSYS nodal-temperature export so the importer can be demonstrated.
- **Origin:** generated by `workbench_cli` (`wb::syntheticGridCsv(11, 11, 11)`), no external data. Regenerate by running `workbench_cli.exe`.
- **Content:** 11 x 11 x 11 = 1331 nodes on a regular grid over the unit cube (spacing 0.1 m), `node_id` = 1..1331.
- **Formula:** `T = 20 + 80 * exp(-((x-0.2)^2 + (y-0.5)^2 + (z-0.5)^2) / 0.08)` in degC (a smooth hot spot; ambient 20 degC).
- **Units:** `x_m`, `y_m`, `z_m` in metres; `temperature_C` in degrees Celsius.
- **Schema:** header exactly `node_id,x_m,y_m,z_m,temperature_C`; `node_id` unique whole numbers; all other columns finite decimal numbers; comma separated; UTF-8 (BOM and CRLF tolerated).
- **Extension to the ANSYS-style layout:** lines starting with `#` are treated as comments (used for the SYNTHETIC label at the top of the file); blank lines are ignored. Line numbers in error messages count these lines.

## Notes for real ANSYS data
To load a real result, export nodal temperatures (for example from ANSYS Mechanical's result export or a table of nodal values) to a text file, convert coordinates to metres if needed, and rename the columns to the header above. Native ANSYS project/result formats and native CAD solids are out of scope. This importer was only tested with the synthetic file above, never with a real ANSYS export.

## Malformed test fixtures
`tests/data/` contains one deliberately broken file per rejection case (empty, binary, NaN/Inf, wrong header, wrong column count, duplicate `node_id`, ...). They are test inputs only.
