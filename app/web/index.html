Unified Engineering Workbench

CAD geometry: ASCII STL

Drag to rotate, right-drag or shift-drag to pan, wheel to zoom. STL files carry no units; metres are assumed. Binary STL is not supported.

ANSYS-style nodal temperatures (CSV point cloud)

Columns: node_id,x_m,y_m,z_m,temperature_C (metres, °C). The bundled sample is SYNTHETIC, not an actual ANSYS export. Hover or click a node to inspect it.

1D steady thermal FEA — uniform rod, two-node linear elements

Solves −d/dx(kA dT/dx) = qA with T(0) and T(L) prescribed; lateral surfaces insulated, constant properties.

Backpropagation check (Task F)

One neuron: h = tanh(wx+b), ŷ = vh+c, J = ½(ŷ−y)²; x = 1, y = 2, learning rate 0.1. Gradients are hand-derived in C++ (no autodiff) and checked by central differences (ε = 1e-6).

Serial vs multicore batch of independent thermal solves

Each case is a 1D rod solve with random k and q (fixed seed). Only the compute calls are timed: 1 warm-up + 5 measured repetitions, median reported. File loading and rendering are excluded.
